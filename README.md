# Video Poker

Enkel video poker i React (typescript), med router og zustand til state.

## Kom i gang

```bash
npm install
npm run dev
```

Åpne adressen som Vite viser i terminalen (vanligvis `http://localhost:5173`).

## Skript

- `npm run dev` – utviklingsserver
- `npm run build` – produksjonsbygg
- `npm run preview` – forhåndsvis bygg

## Struktur

- `src/pages/` – skjermbilder (spill, regler, spillere)
- `src/components/` – gjenbrukbare komponenter (`Card`, `Game`, m.m.)
- `src/store/` – Zustand med localStorage
- `src/utils/` – kortstokk, håndevaluering, utbetalinger
